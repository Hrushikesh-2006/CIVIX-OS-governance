## 📌 Executive Summary

**CIVIX OS** is a state-of-the-art civic operating system engineered to modernize public municipal management and bridge the gap between citizens and municipal authorities. 

By pairing **Google Gemini AI Vision** for autonomous complaint auto-triage with a **100% Public Audit Trail**, CIVIX OS eliminates administrative delays, prevents fund misallocation, and reduces government corruption. 

Citizens earn **+10 Civic Coins** for reporting issues, track officer action timestamps in real time, and climb the city **Champions Leaderboard**, while department officers manage dispatch tickets requiring verified **After-Repair Dual Photo Proofs** before closure.

## ⚡ Comprehensive Feature Breakdown

### 🗺️ 1. Interactive Neighborhood GPS Issue Map
Citizens can view all active complaints around their exact neighborhood on an interactive Leaflet/OpenStreetMap interface. Each pin is color-coded by department and severity.

### 📊 2. District-Wise Day-to-Day & Monthly Telemetry
Analytics hub tracking day-to-day and month-to-month complaint volumes for your district (e.g. *Sheriguda, Ibrahimpatnam mandal, Ranga Reddy District*). Includes live trend indicators (*Increasing / Decreasing*).

### 📢 3. Official Public Advisories & Road Closures
Dedicated broadcast channel (`/announcements`) where verified officials broadcast urgent public notices regarding road work, scheduled power outages, or water supply repairs. Features an animated live ticker on the main feed.

### 🪙 4. Gamified Civic Rewards & Champions Leaderboard
Citizens earn **+10 Civic Coins** per reported issue and **+5 Bonus Coins** when resolved. Unlocks rank badges (*👑 Civic Legend*, *⚡ City Crusader*, *🛡️ Community Hero*, *🔰 Civic Contributor*, *🌱 Active Citizen*) displayed on the city Leaderboard.

### 🤖 5. 24/7 CIVIX AI Query & Doubt Clarifier
Citizens can ask the **CIVIX AI Assistant** (powered by Google Gemini 2.0 REST API) any question about municipal department guidelines, garbage schedules, or water pipelines.

### 🔐 6. Google Authentication via Clerk
Fast 1-click Google OAuth sign-in powered by **Clerk Authentication**, seamlessly synced with local user profiles and coin balances in real time (`onSnapshot`).

### 🌐 7. Instant Multi-Language Support
Full application translation supporting **English**, **తెలుగు (Telugu)**, and **हिंदी (Hindi)** with 1-click language switcher in the navigation bar.

### ⏱️ 8. Officer Delay Timestamp Auditing
Automated timestamp engine (`calculateOfficerResponseDuration`) computing exact officer response duration from submission to resolution (`e.g., Action Time: 2h 15m • Fast Action ⚡`), exposing officer delays to ensure 100% public accountability.

## 🛠️ Local Installation & Setup Guide

### 1. Clone the Repository
```bash
git clone https://github.com/Hrushikesh-2006/CIVIX-OS-governance.git
cd CIVIX-OS-governance
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Set Up Environment Variables (API Keys Hidden Securely)
Create a `.env.local` file in the root directory (Note: `.env.local` is ignored in git for security):
```env
VITE_GEMINI_API_KEY=YOUR_GOOGLE_STUDIO_GEMINI_KEY
VITE_CLERK_PUBLISHABLE_KEY=YOUR_CLERK_PUBLISHABLE_KEY
```

### 4. Run Development Server
```bash
npm run dev
```
Open **`http://localhost:3001`** in your browser to experience CIVIX OS!
